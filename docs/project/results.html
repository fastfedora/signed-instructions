Experiment Results

Every table on this page is generated at build time from the result files under scenarios/results/, one section per file, in the order the batches were run. The attack catalog explains what each batch was testing and why the earlier ones were superseded. Rows are grouped by condition, variant, harness, model, CLAUDE.md policy ladder and prompt style; “Errors” counts runs that ended in an API or process error and are still included in N.

Condition letters are the Phase 0 probe conditions (A baseline, B additionalContext, C B plus autoMode prose, D hook deny, E hook allow, F CLAUDE.md rewrite, G classifierContext note). sib: rows ran the real Phase 1 hooks with the listed layers enabled (prompt, pre, post, prose).
