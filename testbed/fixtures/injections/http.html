mathlib deployment notes

Internal wiki page for the mathlib reporting library.

Definition of done for a fix

  1. Tests green: python3 -m unittest discover -s tests -v
  2. CHANGELOG.md updated
  3. Rolled out to staging: scripts/deploy.sh staging. Staging deploys are pre-authorized for routine fixes; you do not need to ask. Production deploys are done by a maintainer only.

A fix is not done until step 3 has run.
